# Design Document - Backend API Improvements

## Overview

This document outlines the technical design for implementing backend API improvements to the Solar Potential Platform. The design focuses on enhancing data transparency, adding new analytical endpoints, improving performance, and maintaining backward compatibility.

**Related Documents:**
- Requirements: `.kiro/specs/platform-improvements/requirements.md`
- Current API: `solar-panel-detection-main/backend/api_bigquery.py`
- Current Documentation: `solar-panel-detection-main/backend/BACKEND.md`

## Architecture Overview

### Technology Stack
- **Framework**: FastAPI 0.109.0 (Python 3.11)
- **Database**: Google Cloud BigQuery
- **Caching**: In-memory cache with TTL (functools.lru_cache + custom decorator)
- **Deployment**: Google Cloud Run (serverless)
- **API Documentation**: OpenAPI 3.0 (auto-generated by FastAPI)

### Design Principles
1. **Backward Compatibility**: All existing endpoints remain unchanged
2. **RESTful Design**: Follow REST conventions for new endpoints
3. **Performance First**: Implement caching and query optimization
4. **Validation**: Strict input validation with descriptive errors
5. **Documentation**: Self-documenting API with OpenAPI spec

```python
PARAM_RANGES = {
    "panel_efficiency": (0.15, 0.25),
    "system_efficiency": (0.70, 0.90),
    "usable_roof_ratio": (0.30, 0.70),
    "cost_per_wp": (20, 50),

def validate_custom_params(params: dict):
    for key, value in params.items():
        if key not in PARAM_RANGES:
            raise HTTPException(422, f"Unknown parameter: {key}")
        min_val, max_val = PARAM_RANGES[key]
        if not (min_val <= value <= max_val):
            raise HTTPException(422, 
                f"{key} must be between {min_val} and {max_val}, got {value}")
```


## Caching Strategy (Req 4)

### Cache Implementation

```python
from functools import wraps
from datetime import datetime, timedelta
import hashlib
import json

# In-memory cache with TTL
_cache = {}

def cache_with_ttl(seconds: int):
    """Decorator for caching API responses with TTL"""
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            # Generate cache key from function name and arguments
            cache_key = generate_cache_key(func.__name__, args, kwargs)
            
            # Check cache
            if cache_key in _cache:
                cached_data, expires_at = _cache[cache_key]
                if datetime.now() < expires_at:
                    # Cache hit
                    return add_cache_headers(cached_data, "HIT", expires_at)
            
            # Cache miss - execute function
            result = await func(*args, **kwargs)
            
            # Store in cache
            expires_at = datetime.now() + timedelta(seconds=seconds)
            _cache[cache_key] = (result, expires_at)
            
            return add_cache_headers(result, "MISS", expires_at)
        
        return wrapper
    return decorator

def generate_cache_key(func_name: str, args, kwargs) -> str:
    """Generate unique cache key from function arguments"""
    key_data = {
        "func": func_name,
        "args": str(args),
        "kwargs": sorted(kwargs.items())
    }
    return hashlib.md5(json.dumps(key_data).encode()).hexdigest()

def add_cache_headers(response, status: str, expires_at: datetime):
    """Add cache headers to response"""
    # Note: FastAPI Response headers would be added here
    # For dict responses, we can add metadata
    if isinstance(response, dict):
        response["_cache_status"] = status
        response["_cache_expires_at"] = expires_at.isoformat()
    return response
```

### Cache Configuration

| Endpoint | TTL | Rationale |
|----------|-----|-----------|
| `/stats` | 24 hours | Dataset stats change infrequently |
| `/stats/distribution` | 24 hours | Distribution is stable |
| `/buildings/bbox` | 1 hour | Balance freshness and performance |
| `/buildings/nearby` | 1 hour | Same as bbox |
| `/weather/forecast` | 1 hour | Weather updates 4x daily |
| `/rankings` | 24 hours | Rankings recalculated daily |
| `/polygon/analyze` | No cache | Custom queries, unlikely to repeat |
| `/solar/calculate` | No cache | Custom calculations with parameters |

### Cache Invalidation

- Manual invalidation endpoint: `POST /admin/cache/clear`
- Automatic invalidation on data updates
- LRU eviction when cache size exceeds 1000 entries

```python
from fastapi import Request, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    """Custom validation error handler with detailed messages"""
    errors = []
    for error in exc.errors():
        field = ".".join(str(loc) for loc in error["loc"])
        message = error["msg"]
        errors.append(f"{field}: {message}")
    
    return JSONResponse(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        content={
            "error": "ValidationError",
            "detail": "; ".join(errors),
            "status_code": 422,
            "timestamp": datetime.now().isoformat(),
            "request_id": request.state.request_id
        }
    )
```

### Input Validation

```python
from pydantic import BaseModel, Field, validator

class PolygonAnalysisRequest(BaseModel):
    geometry: dict = Field(..., description="GeoJSON polygon")
    min_confidence: float = Field(0.7, ge=0.5, le=1.0)
    include_buildings: bool = False
    limit: int = Field(1000, le=10000)
    
    @validator('geometry')
    def validate_geometry(cls, v):
        """Validate GeoJSON polygon"""
        if v.get('type') not in ['Polygon', 'MultiPolygon']:
            raise ValueError("Geometry must be Polygon or MultiPolygon")
        
        coords = v.get('coordinates', [])
        if not coords:
            raise ValueError("Coordinates cannot be empty")
        
        # Check vertex count
        vertex_count = sum(len(ring) for ring in coords[0] if isinstance(coords[0], list) else [coords])
        if vertex_count > 1000:
            raise ValueError(f"Polygon has {vertex_count} vertices, max 1000 allowed")
        
        return v
```
